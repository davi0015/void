**Fixes**

- Legacy residue is reclaimed once at startup instead of waiting for you to open
  each thread — checkpoint records from the removed feature, two fields the thread
  model no longer has, and request logs older than seven days. Every stored key is
  read at launch, so that residue was paid for on every start: 287 checkpoint
  records were still present across 23 threads on the profile this was measured
  against, some last opened weeks earlier (#144)
- Compaction no longer drops a message. A thread whose message keys had a gap was
  renumbered on load while its boundary stayed put, so the message at the boundary
  moved inside the summarised prefix without ever being summarised — it was in
  neither, and stayed that way (#148)
- Duplicated threads keep their attachments. The copy's file paths were rebuilt as
  objects that could not be rendered, so its chips broke, and the damage survived a
  restart (#147)
- An absolute Windows path in a reply now becomes a link. The comparison built its
  prefix with a forward slash, so `C:\...` never matched; relative paths and `./`
  already worked (#145)

**Internal** — a multiagent design revision that drops agent role files, permission
attenuation and budgets, continuity notes, and a test-harness fix that lets a fixture
seed more keys than one command line can hold (#143, #146, #149, #150).
