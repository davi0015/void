**Fixes**

- Terminal input works on Windows again. Two independent causes, both on the Windows
  input path: with node-pty 1.2.0 the pty host utility process never heartbeats, so no
  terminal process was created and keystrokes queued forever, and the macOS fd
  workaround from #121 wrote input with `fs.write(ptyProcess.fd, ...)` on every platform
  — on Windows `fd` is a console handle rather than a file descriptor, so keystrokes went
  where nothing reads them while output kept flowing. Text appeared in the widget and no
  keystroke reached wsl, powershell or cmd. node-pty is back on ^1.1.0-beta33 and the
  workaround is gated to darwin; `terminal-input.test.mjs` types into a real terminal and
  checks the shell ran the command (#155)
- `run_command` results show the resolve reason instead of `· [object Object]` —
  `TerminalResolveReason` is a discriminated union, and the summary was interpolating the
  object rather than formatting it (#156)

**New**

- External chat integration: the transport for driving a chat thread from outside the
  editor (Teams first, Slack later). A conversation-level protocol over localhost —
  newline-delimited JSON, a handshake with a pairing token, envelope ids and acks — and
  the browser service that routes proxy messages into real threads while streaming
  presentation-safe updates back. Raw tool results are structurally absent from every
  outbound type, so redaction is enforced by the compiler instead of by remembering;
  approvals round-trip with timeout-to-reject, and a conversation's thread binding
  survives a restart. The server starts with the workbench on `127.0.0.1:4757`; there is
  no in-editor UI for it yet, so this release is the transport and the routing underneath
  one (#156)

**Internal** — the release note is now a file in this repository, used verbatim as the
release body, so a tag without one fails the release step rather than publishing an
empty page (#152), and CI runs the node tier on every push (#153).

**Known limit, stated rather than implied** — the end-to-end tier has still only ever run
on Windows. CI compiles on `ubuntu-22.04` and runs the node tier, never the end-to-end
tier, so the macOS and Linux artifacts are compiled and typechecked rather than
behaviourally verified.
